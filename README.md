# Imran Production TV — Android App

Professional Android WebView app for the existing Imran Production TV website.

Website:
https://imran223344.github.io/imranproductiontv/

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select **Build > Build APK(s)**.
4. Install the generated APK on Android.

The app opens the website inside the app, keeps internal navigation in-app, and sends external links (such as YouTube) to the appropriate Android app/browser.
